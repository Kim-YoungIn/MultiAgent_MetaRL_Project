## D-024 후속 상태 — 관계형 v2

이하1절 이후는 v1 시점의 한계 기록이다. 현재 생성기는 의미 관계·상성·조건·보상·예외를 분리하고,
현재 일치항 강제를 해제했으며 최선반응 집합과 compiled PD를 기록한다. Q+Expected SARSA 상대를
사용하고 prefix AUC/기술적 기울기도 추가했다. 이 확장이 전략 다양성이나 탐색 성공의 증명은 아니다.
새 규칙 학습 .260921 < 랜덤 .292584. 예외 구조는 평균만 개선하고 seed 부호가 섞인다.
새 상대 설정 절대 성능 .127238→.212153, G .202276→.196373으로 효과 해석은 분리해야 한다.
상대 상태/방문 상태 유도는 미검증 후보다. 단일 catalog seed·Q 학생·짧은 예산·약한 메타 학습 및
조건부 G의 해석 한계가 남는다. [최신 검토](../sessions/11_relational_rules_review.md)를 우선한다.

## 기준과 증거의 범위

기준은 D-021~D-023의 **탐색 전략을 학습해 새 에이전트의 적응을 돕는가**이다.

## 1. 현재 결과로 확인한 한계

| 평가 | 초기 탐색 후 성능 | 학습 탐색 후 성능 | 랜덤 탐색 | ε-greedy 탐색 |
|---|---:|---:|---:|---:|
| 새 규칙 | .047773 | .082870 | .118386 | .091402 |
| 중첩 구조 | .344097 | .308102 | .375694 | .355208 |
| 미학습 상대 학습 설정 | .235957 | .281893 | .161998 | .199460 |

조건당3 learning seeds 평균,같은 후속12턴의 보상/step이다.
새 규칙은 세 seed 모두 초기 대비 개선했지만 랜덤보다 낮았다.
중첩 구조는 세 seed 모두 초기 대비 하락했다. 미학습 상대 설정에서는 세 seed 모두
초기/랜덤/ε-greedy보다 높았다. 일부 개선은 있지만 범용 탐색 우위는 확보하지 못했다.
미학습 설정은 같은 Q 알고리즘의 학습률/탐색률 조합이며 새로운 상대 학습법은 아니다.

## 2. 측정 지표와 메타 학습 목표

**확인:** 현재 주 지표는 후속 평균 보상과 G=경험 유지 학생−학생 Q 제거 대조다.
턴별 곡선·초기/후기 평균은 기록하지만 적응 곡선의 기울기나 목표 성능 도달 시간은 계산하지 않는다.
PPO의 parameter gradient와 성능 지표를 혼동하지 않는다.

**한계:** G는 순수 정보량/적응 속도/절대 성능의 동일한 지표가 아니다.
제거 분기도 탐색이 만든 상대 상태에 의존하므로 절대 보상 개선의 unbiased baseline이 아니다.
미학습 상대 설정에서 반복 탐색은 G≈.1303으로 학습 탐색≈.0656보다 높지만,
절대 후속 성능은 .2439로 학습 탐색 .2819보다 낮아 지표 순위가 실제로 다르다.

**검토:** 전체 경험 예산에 대한 적응 곡선·초기 누적 성능·동일 예산 후 절대 성능,
탐색 비용을 포함한 실제 게임 성능과 G를 함께 사용할 성공 기준.
기울기만 쓰면 이미 빠르게 높은 성능에 도달한 평탄한 곡선을 과소평가할 수 있다.
평가에서 먼저 정의한 지표를 바탕으로 학습 목표 유지/수정을 결정해야 하며,
현재 결과에 유리한 지표를 사후 선택하지 않는다.

## 3. Generator의 표현 문법과 실제 생성 분포

**확인:** Boolean/if/add/scale 문법과 tensor Compiler는 있지만 실제 sampler는 제한된
atom/and/or/nested 형태이며 모든 보상식에 현재 자기·상대 행동 일치 관계가 들어간다.
문법이 표현할 수 있는 범위와 실제 표본 분포의 범위가 다르다.

**한계:** 계수·표현식·tensor가 다르다고 전략이 다른 것은 아니다.
현재 filter는 자기/상대의 현재 행동 축에 보상이 의존하는지 검사할 뿐,
상대에 따라 좋은 대응이 달라지는지까지 보장하지 않는다.
예를 들어 F(a,b)=f(a)+g(b)는 양쪽 축에 의존해도 자기 최적 행동은 상대와 무관할 수 있다.
원시/정규화/재명명 tensor 거리와 구조 token 차이도 전략적 거리의 검증된 대용 지표는 아니다.

**검토:** 공통 일치관계의 의무화를 줄인 생성 분포,다른 관계/조건/보상 결합,
재사용할 구조와 미학습 조합의 명세,상대별 좋은 대응의 차이와 정보 획득 가능성.
무제한 DSL이나 모델이 잘 푸는 게임만 고르는 선별을 목표로 하지 않는다.

## 4. MA 환경과 학습 상대의 범위

**확인:** 상대는 실제 Q와 전략을 학습한다. 평가1080trials에서 실제 의사결정의 약50.29%가
학습된 비균등 분포를 사용했다. 고정 상대만 남아 있다는 과거 한계는 현 경로에서 해결했다.

**한계:** 학생과 상대 모두 같은 계열 tabular Q이고 상대 variation도 alpha/epsilon 중심이다.
양쪽은 매 task에 zero-Q로 시작하고12+12턴만 상호작용한다.
다른 학습법·학습된 상대의 초기 전략·긴 기억·장기 상호적응·상대가 이전 task 경험을
축적하는 조건은 다루지 않는다. 서로 다른 학습 에이전트 군에 대한 일반성을 주장할 수 없다.

**검토:** 학습 규칙/기억/초기 전략/반응 속도가 다른 상대,더 긴 상호작용,
상대가 달라지면 실제 유리한 대응이 달라지는 조합. 모든 확장을 동시에 도입할 필요는 없다.
2인/n=3/Memory-One/대칭 보상은 현재 범위이지 그 자체로 확인된 실패 원인은 아니다.

## 5. 정보 수집과 상대에 대한 영향의 혼합

**확인:** 탐색 행동은 학생 경험과 상대 학습 상태를 동시에 바꾼다.
제거 대조는 같은 탐색 후 상대 상태에서 출발하지만 이후 두 분기의 상대 학습은 달라질 수 있다.

**한계:** 좋은 후속 성능이 정보를 알아내서인지,유용한 상태를 방문해서인지,
상대를 유리한 전략으로 유도해서인지 완전히 분리되지 않는다.
후속 구간에서도 학생/상대가 계속 학습하므로 곡선의 상승이 탐색 경험만의 효과는 아니다.

**검토:** 유지 경험 효과·상태 방문·상대 유도의 해석을 구분하는 제한된 대조와 기록.
본 실험 전체를 고정 상대나 강제 동일 상대 trajectory로 되돌리지 않는다.

## 6. 특정 학습기와 모델에 의존한 결과

**확인:** 탐색자는 공유 행동별 GRU/actor,학생은 관측4필드를 key로 하는 Q다.
ε-greedy 기준은 학생의 명시적 Q를 활용하고 신경망은 관측 이력을 사용한다.
평가에서 경험 유지/제거에 따라 행동과 성능이 달라지고 탐색자 weights도 실제 갱신됐다.

**미확정:** 학생의 경험 활용 한계,탐색자의 표현/최적화,짧은 예산 중 무엇이 부진의 주원인인지.
숨은 규칙과 상대 Q 상태 때문에4필드 관측은 일반적으로 완전 Markov state가 아니다.
모델 크기 부족이나 PPO의 부적합을 현재 결과만으로 확정하지 않는다.

**검토:** 고정한 환경/예산에서 제한된 참조 모델 또는 학생 학습법 비교.
이를 환경/Generator 확장의 무기한 선행 관문으로 만들지 않는다.

## 7. 일반화·통계·H1/H2

**확인:** 한 catalog에서 학습12개/새6개/중첩6개 규칙,3 learning seeds,과제당 평가2회다.
중첩 집합에서는 조건 깊이와 보상 합성이 함께 바뀐다.

**한계:** catalog를 새로 생성했을 때의 변동,새 학습 알고리즘의 상대,행동 수 간 학습 전이는 미검증이다.
제한된 seed의 개선 방향만으로 안정된 우위/통계적 확증을 주장하지 않는다.
현재 본 목적 실험은 탐색 전략 비교이며 H1의 다양성 효과와 H2의 구조 공유 효과를
각각 분리 조작한 연구는 아니다. 기존 whole-trial diversity 파일럿과 혼동하지 않는다.

**검토:** 학습 seed·평가 난수·규칙 catalog 변동을 구분하고,유사성·노출량·난이도를 통제할 후속 설계.
동일 총예산은 과제당 노출 감소까지 포함한다는 점을 표시한다.

## 8. 이미 해결한 문제와 남은 품질 항목

- 최초 환경/Compiler/기록 및 Toy A/B 최소 통합은 완료했다.
- 기존 ordinal 행동 번호 편향을 발견해 순열 대칭 정책을 추가했다. 모든 표현/학습 문제의 해결은 아니다.
- 탐색 경험의 downstream 학습 신호와 실제 학습 상대를 구현했다.
- 같은 상대 상태의 paired 대조,학습된 상대 정책의 실제 사용,관측 경계와 경계 bootstrap을 검증했다.
- 전체114개 테스트와24개 checkpoint/split 재평가를 통과했다. 이는 소프트웨어/재현성 증거이며 가설 검증의 대체물이 아니다.
- 브라우저 시각 검수와 더 넓은 실행 환경 검증은 남아 있다. 원자료는 로컬 runs에 있고 동료는 README로 독립 실행한다.

## 다음 검토의 제안 우선순위 — 새 구현 결정 아님

1. 평가 지표/성공 기준과 Generator·MA 환경 확장을 함께 명세한다.
   국소 성능 튜닝만 계속하거나 지표 확정을 환경 확장의 영구 관문으로 삼지 않는다.
2. 생성 분포의 전략적 다양성과 상대 학습 방식의 범위를 확장하되 실제 비교에서는 각 변화 축을 구분한다.
3. 같은 조건에서 필요한 참조 모델/학생 비교와 반복 실험을 제한적으로 수행한다.
4. 그 기반에서 탐색의 효과를 중심에 둔 H1/H2 비교를 설계한다.

GPU 전환·더 큰 n·범용 DSL·진화 population·self-play는 자동 처방이 아니다.
관찰된 부진을 설명하거나 핵심 질문을 판별하는 데 필요한 경우에만 범위를 정해 채택한다.
