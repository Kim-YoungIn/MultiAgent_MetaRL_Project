# 첫 생성 게임 전이 실험 — 결과와 독립 검토 (2026-11-14)

## 수행 범위

`Generated_Transfer_Contract.md`의 규칙 생성→MA 구성→공통 정책 학습→held-out 평가→분석 경로를
실제로 실행했다. 기본12회 학습과103개 테스트,48개 checkpoint/split 재평가를 메인이 확인했다.
구현 단위와 연구 성공을 구분한다. 상세 실행 증거는 `../Implementation_Status.md`에 있다.
실행 결과는 `runs/generated_transfer_v1/`에 두며 동료에게 사본을 넣지 않는다.
README의 `mamrl.generated_experiment`로 독립 실행한다.

## 독립 검증이 바꾼 내용

- copy anchor를 모든 학습 규칙에 유지해 high-rule의 실제 규칙 수가 상대 조건에 따라9/12로 바뀌던 문제를 수정했다.
- manifest 로드 시 사전 정의된 split/condition을 재검사해 held-out pair를 train으로 바꾸는 변조를 거부한다.
- 원시 거리는 source_rule, 정규화 거리는 실제 플레이 rule을 사용하도록 분리했다.
- 정보 경계·동시 행동·상대 episode reset·full-trial replay, DP와 첫 보상정보 제거 대조를 독립 검증했다.
- 같은 seed 초기 정책과 평가 과제/외생 seed, checkpoint 재평가, source hash와 출력 덮어쓰기 거부를 확인했다.

## 독립 research_critic 결과와 메인의 최종 해석

1. 규칙 증가 이득은 일관되지 않았다. low-opponent의 제외 조합 평가에서는 세 seed 모두 하락했다.
   이것을 H1 기각으로 부르지 않는다. 노출·유사성·평가 친숙도와 약한 학습이 해석을 제한한다.
2. 상대 증가의 새 상대 평가 차이는 규칙4에서+.0331, 규칙12에서+.0230으로 각각 세 seed 모두 양수였다.
   하지만 최고 학습 점수.1748은 초기.1738과 거의 같고 단순 repeat.3789보다 낮다.
   '빠른 적응 성공'보다 copy-only 학습 대비 상대적 손상 완화로 기술한다. 과적합 완화는 후속 가설이다.
3. high/high의 새 상대 memory delta+.0136은 seed별+.00139/+.03895/+.00058로 seed17에 집중됐다.
   다른 집합의 부호도 섞여 일관된 episode 간 기억 활용 성공을 주장할 수 없다.
4. 온라인 Q와 catalog posterior는 경험 활용 가능성을 일부 보여준다. posterior는 평가 규칙까지
   아는 강한 prior이고 Q는 평가 중 학습하므로 동등 정보/알고리즘 비교가 아니다. 단순 정책 곡선도 함께 본다.
5. combination은 high/high에서만 전부 본 요소의 새 조합이다. 각 조건의 seen-rule/opponent/pair를 표시했다.
   중첩 집합은 조건과 보상 합성이 함께 달라지는 분포 변화이지 조건 깊이만의 실험이 아니다.
6. 정보 가치 예시는 생성 후 분석적으로 찾고 neural 결과 전에 고정했다. 알려진 두 규칙·상대·horizon과
   특정 초기 상태에 한정한 존재 사례이며 사전등록된 대표 표본이나 학습된 능동 탐색의 증거가 아니다.
7. 전체 trial SE는 고정 과제들의 차이도 섞인 기술 통계이고 학습 seed SD와 다르다.
   late−early는 상태 방문 변화도 포함한다. 보상 정규화도 win_stay 행동을 보존하지 않을 수 있다.

위 검토로 학습 분포·예산·최종 weights를 사후 변경하지 않았다.
familiarity metadata·보고 문구·renderer 보완은 reporting_sources/별도 hash로 보존했다.
브라우저의 시각적 레이아웃 검수는 수행하지 않았다.

## 다음 연구 주안점 — 아직 새 실험을 채택한 것은 아님

현재 생성 분포를 고정한 상태에서 초기 대비 변화와 규칙/상대 친숙도, 단순 정책 대비 격차를 먼저 분석한다.
그다음 제한된 한 번의 참조 모델 비교로 action-set 구조와 일반 GRU의 경험 활용 차이를 확인하는 것이 후보이다.
Generator를 다시 무기한 미루거나, 모델 점수가 좋은 게임만 골라내거나,
문법·과제·예산·모델을 동시에 바꿔 결과를 살리는 방식은 피한다.
H1의 다양성 효과와 H2의 구조 공유 효과를 분리하려면 노출량·거리·보상 합성을 통제하는 후속 설계가 필요하다.
