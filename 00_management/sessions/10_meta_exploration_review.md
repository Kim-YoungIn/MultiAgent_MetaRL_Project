# 메타 탐색 본 목적 파일럿 — 조정·구현·결과 (2026-11-14)

## 연구 조정

사용자가 강조한 것은 탐색 전략을 개선하는 상위 학습과, 그 경험으로 새 에이전트가 더 빨리
적응하는지의 검증이다. 단일 플레이 정책의 전체 보상과 고정 반응형 상대만으로 대신하지 않는다.
D-023은 이 목적을 한 가지 통제된 teacher/student/learning-opponent 프로토콜로 구현했다.
부모 네트워크·진화·생존 선택을 문자 그대로 재현하거나 원 제안서를 소급 변경하지 않았다.

## 실제 역할과 목적함수

- Teacher: 관측4필드와 recurrent 기억으로 탐색 행동 선택. 신경망은 rule·상대 profile·학생 Q를 입력받지 않는다.
- Student: 같은 온라인 Q 학습법·초기 조건에서 teacher 경험으로 학습하고 이후 greedy Q로 플레이한다.
- Opponent: 자신의 관측/보상으로 온라인 Q를 갱신하며 평가 중에도 학습한다.
- Meta update: 탐색 sequence의 downstream G를 PPO target으로 사용. Q 업데이트를 미분하지 않는다.
- G: 학생 경험 유지 후 성능−동일 상대 상태에서 학생 Q만 제거한 성능. 두 분기에서 이후 학습은 계속한다.

탐색12+실제 후속12+대조12의 simulation 비용을 기록했다.
episode 경계에서 학생과 상대의 Q/RNG를 유지하고 trial 경계에서 초기화한다.
탐색 비용·후속 절대 성능·G·전체 실제 게임 성능을 구분한다.
미학습 규칙/상대 결과로 checkpoint를 선택하거나 예산을 늘리지 않았다.

## 독립 검토가 보완한 부분

1. G의 제거 대조도 탐색이 만들어낸 상대 상태에 의존한다. 절대 보상의 unbiased baseline이 아니며,
   G 증가와 실제 후속 성능 개선을 함께 보고해야 한다.
2. 업데이트한 관측을 재방문하지 않으면 상대 Q 변화가 실제 게임에 쓰이지 않을 수 있다.
   pre-action 분포와 비균등 선택 비율을 기록하고 독립 손계산 재생으로 검증했다.
3. 입력 경계·양자 동시 행동·Q clone/RNG·Q 제거·경계 bootstrap·다운stream-only target과
   target 부호에 따른 actor gradient·n3/4/5 replay·CLI 재평가/덮어쓰기를 검사했다.

Worker와 독립 validator가 내부 구현/검증을 분리했다. 독립 검토자들은 설계 단계에서 의견을 제공했다.
추가 agent 검토는 사용 한도로 중단됐으며 최종 전체114개 테스트와 실제 결과 검증/해석은 메인이 책임졌다.

## 결과

3seeds×40updates,같은 catalog에서 학습한 메타 탐색을 초기·랜덤·ε-greedy·반복과 비교했다.
실제 수치는 [당시 구현 증거](../archive/Implementation_Status.md),원자료는 `runs/meta_exploration_v1/`를 따른다.

- 새 규칙: 학습 전보다 세 seed 모두 후속 성능 상승(+.0351 평균),랜덤보다 세 seed 모두 낮음(−.0355 평균).
- 중첩 구조: 초기 대비 세 seed 모두 하락(−.0360 평균),랜덤/ε-greedy보다 낮음.
- 미학습 상대 학습 설정: 초기 대비+.0459,랜덤 대비+.1199,ε-greedy 대비+.0824 평균;
  각 비교에서 세 seed 모두 양수. 같은 Q 알고리즘의 설정 변화이며 새로운 학습 알고리즘은 아님.
- 실제 상대 의사결정의 약50.29%가 learned-Q에 따른 비균등 분포였다(모든 방법/평가1080trials 집계).
  이는 전략 갱신의 사용을 확인하는 지표이지 상대가 충분히 강하거나 복잡하다는 보장은 아니다.

## 해석과 다음 판단

이제 과제가 연구 목적을 직접 시험하는 구조에 가깝지만 범용적 탐색 우위는 아직 없다.
랜덤보다 낮은 새 규칙 성능과 중첩 전이 실패를 보존하고 어떤 탐색 경험 차이가 이를 만드는지 분석해야 한다.
학생 Q key는 관측4필드이며 한정된 예산에서 POMDP/비정상 상대를 근사한다.
이 결과는 특정 teacher+student 조합의 결과이며 모든 meta exploration의 한계로 확대하지 않는다.

다음 후보는 같은 분포/예산을 고정한 목표 함수 대안 또는 제한된 참조 탐색 모델 비교이다.
G만 높이고 제거 대조를 악화시키는 전략을 선택하지 않도록 절대 성능 기준을 유지한다.
학습 상대 알고리즘 확대·생성 문법 확대·진화 population은 별도 결정이며 동시에 모두 바꾸지 않는다.
결과가 좋은 과제를 사후 선별하거나 무기한 국소 튜닝을 선행 관문으로 두지 않는다.
