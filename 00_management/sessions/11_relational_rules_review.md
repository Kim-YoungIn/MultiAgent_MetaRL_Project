# 관계형 규칙과 학습 상대 확장 검토 — 2026-11-14

## 질문과 채택 범위

사용자는 반복을 협력,변경을 배신으로 해석해 사회적 게임도 표현할 수 있다는 생각노트와
독립 탐구·조정 후 진행을 요청했다. 의미 이름을 요구사항으로 자동 고정하지 않고 독립 검토 후
D-024로 관계형 생성기와 MA 상대 확장을 채택했다. 연구 목적은 탐색 경험의 적응 가치다.
게임 생성 자체의 정교함이나 PD 추가가 연구 성공을 대신하지 않는다.

의미 문법/Compiler는 worker,독립 계약 테스트는 validator,설계·결과 해석은 research_critic,
카탈로그·상대 통합·실행·최종 검증은 메인이 담당했다. 분리 가능한 파일만 병렬 작업했다.

## 반복/변경의 의미와 PD

반복=C,변경=D로 두고 CC=R,CD=S,DC=T,DD=P를 배정한다.
PD의 T>R>P>S와 반복 게임에서 자주 추가하는2R>T+S를 분리한다.
모든 이전 상태에서 양쪽의 C/D 선택과 네 사분면이 도달 가능하고,
같은 사분면의 모든 행동 조합이 동일한 보상이어야 정확한 embedding으로 판정한다.
단순 명명이나 하나의 예제 표만으로 판정하지 않는다.

n3에서 C 행동1개,D 행동2개다. 균등 행동은 C/D 균등이 아니므로 .5/.5 balanced와 항상 변경
대조군을 추가했다. 이들은 규칙을 보지 않는다. D들의 즉시 보상이 같아도 다음의 물리 행동이
다르므로 학습 상대와의 장기 동등성은 보장되지 않는다. 보너스/예외는 PD를 깨뜨릴 수 있어
최종 보상표로 재판정한다. 단계 지배전략은 능동 탐색 필요성의 보장이 아니므로 PD는 대조층이다.

문헌: [Axelrod/Hamilton 1981](https://pubmed.ncbi.nlm.nih.gov/7466396/),
[Nowak 2006](https://pmc.ncbi.nlm.nih.gov/articles/PMC3279745/).
이는 의미/보상 조건 검토이며 해당 진화·협력 실험의 재현은 아니다.

## 실제 구현과 사전 고정한 분포

[계약](../../04_design/Relational_Game_Contract.md)에 따라 상성표와 eq/ne/win/draw/lose,
Boolean,조건부 보상·가산·배율·예외를 분리했다. 과거 현재 행동 일치항을 모든 식에 강제하지 않는다.
공통 F와 플레이어 교환 대칭,Memory-One,n3,네 관측,온라인 Q 학생,탐색자 구조,G,K/H는 유지했다.

28규칙은12학습(4기본 가족당3),8fresh(가족당2),8예외 가족 holdout이다.
사회적 유인층을 훈련 전에 고정했다: 학습 PD/조정/반조정,새 규칙 협력 우세/PD.
102후보 중74개는 유인층 불일치로 제외했다. 상수/중복 제외는 이번 seed에서0개였다.
이 필터는 컴파일된 게임 의미 기준이며 신경망 성능에 따른 선별이 아니다.

r000 원보상은 R3,S0,T5,P1이다. 새 PD r016은 R0,S−3,T3,P−1이며
T>R>P>S를 만족하지만2R>T+S는 거짓(등호)이다. 조정/반조정 태그를 더 강한 stag-hunt/chicken
정의와 동일시하지 않는다. 원식/실제 정규화 명세·seed·hash·최선반응 집합을 보존했다.
보상/구문/재명명 거리는 전략적 거리의 검증된 대리 지표가 아니다.

상대는 Q(.3,.15)와 Expected SARSA(.5,.2)로 훈련하며,Expected SARSA(.7,.1)는 최종 평가한다.
학생은 동일 Q(.5,.95),평가 greedy다. 상대 algorithm을 clone/제거 분기에서도 보존한다.
새 상대 평가의 알고리즘은 이미 훈련에 포함됐으므로 미사용 알고리즘 전이가 아니다.

예외 구조는 랜덤 대비 평균+.023727이지만 seed 부호가 섞이고 ε-greedy/balanced보다 낮다.

가능한 설명이지만 이번 실험에서 원인으로 확인한 것은 아니다.

v1과 생성 분포·상대 알고리즘이 함께 달라진 새 프로토콜이다. 점수 차이를 단일 변경 효과로
