# Reference Papers

`core/`는 프로포절에 기재된 5개 논문, `additional/`은 대화에서 나온 Exploration 관련 추가 2개 논문이다.

- `References.tsv` — 전체 서지·공식 웹페이지·공식 PDF 직접 링크 목록.
- `core/`와 `additional/`의 논문별 `.md` — 짧은 개요, 프로젝트 관련성, 주의할 차이.
- `.url` — Windows에서 공식 원문 PDF를 브라우저로 여는 Internet Shortcut.

**논문 PDF 바이너리는 포함하지 않는다.** 다운로드 환경 제약으로 직접 보관하지 못했고, 대신 공식 PDF URL을 검증하여 기록했다. 원문의 해석과 구현 방식이 다를 수 있으므로 검토 시 원문을 우선한다.
