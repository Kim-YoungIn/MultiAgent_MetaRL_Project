# R02 — RL²: Fast Reinforcement Learning via Slow Reinforcement Learning

- **Authors:** Yan Duan et al.
- **Year / Venue:** 2016 / arXiv / ICLR 2017 submission
- **Role:** CORE
- **Official page:** https://arxiv.org/abs/1611.02779
- **Official PDF:** https://arxiv.org/pdf/1611.02779

## 핵심 내용

RNN의 내부 상태가 task 내 행동·보상·경계 정보를 축적해 새로운 환경에서 빠르게 적응하도록 학습하는 메타 강화학습 구조.

## 우리 프로젝트에 연결되는 지점

Task 경계에서 recurrent state 초기화, 같은 task의 episode 사이에서 유지하는 프로토콜.

## 적용 시 주의

RNN의 hidden state를 통한 적응과 PPO gradient update를 동일시하면 안 된다.

**지위:** 참고 자료이며 구현 결정이 아니다.
