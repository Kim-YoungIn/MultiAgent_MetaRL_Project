# R05 — Multi-Agent Meta-Reinforcement Learning: Sharper Convergence Rates with Task Similarity

- **Authors:** Weichao Mao et al.
- **Year / Venue:** 2023 / NeurIPS 2023
- **Role:** CORE
- **Official page:** https://proceedings.neurips.cc/paper_files/paper/2023/hash/d1b1a091088904cbc7f7faa2b45c8f36-Abstract-Conference.html

## 핵심 내용

여러 MARL task가 유사할 때 meta-learning이 이론적으로 유리해질 수 있는 조건과 수렴 결과를 분석.

## 우리 프로젝트에 연결되는 지점

Task similarity를 제어하는 실험 설계와 H2의 연구 동기.

## 적용 시 주의

연구의 핵심 지표는 게임이론적 수렴이며, 메타 테스트 시 recurrent adaptation curve와 동일한 문제는 아니다.
