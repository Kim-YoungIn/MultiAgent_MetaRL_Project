## **게임 규칙 생성 및 보상 텐서 설계 — 정리본**

### **1. 기본 구조**

게임은 임의의 보상값을 배정하는 것이 아니라, **논리적으로 정의된 규칙을 생성하고 이를 보상 텐서로 변환하는 방식**으로 구성한다.

\\[ R_i(a\_{t-1},b\_{t-1},a_t,b_t) \\]

- 기본 Action Space: \\(n=4\\)
- 검증 시 확장 후보: \\(n=5\\)
- State Space: \\(n^2\\) (직전 양측 행동)
- Reward Tensor: 플레이어별 \\(n^4\\)개 항목
- Observation: 직전 자신의 행동, 상대 행동, 자신의 보상
- 규칙은 에이전트에게 직접 공개하지 않는다.

보상 텐서의 형태는 공통으로 유지하며, 게임의 다양성은 **텐서를 생성하는 논리적 규칙**에서 발생한다.

### **3. Rule Generator**

규칙 생성 과정은 다음과 같다.

\\[ \boxed{ \text{Logical Primitives} \rightarrow \text{Rule Composition} \rightarrow \text{Parameter Sampling} \rightarrow \text{Reward Tensor} } \\]

**Logical Primitives:** 행동의 일치·불일치, 순서, 특정 조합, 행동 간 관계 등 기본 조건을 정의한다.

**Rule Composition:** 조건들을 논리 연산과 보상 연산으로 결합한다. 보상 부여, 페널티, 배율, 조건부 대체 등을 지원한다.

**Parameter Sampling:** 규칙 생성 시 계수와 기타 파라미터를 지정된 후보 집합에서 추출한다.

**Rule Compiler:** 완성된 규칙을 모든 행동 조합에 적용하여 \\(n^x\\) 보상 텐서로 변환한다.

### **4. 보상 계수**

기본 계수 후보 집합은 다음과 같다.

\\[ C=\\{0,1,2,3,4\\} \\]

행동별 계수는 고정하지 않고 **규칙 생성 단계에서 선택**한다.

- 규칙에 따라 각 행동에 서로 다른 계수를 배정하거나 중복을 허용할 수 있다.
- 계수의 선택과 배정 방식 역시 Rule Generator가 정의한다.
- 생성이 완료된 게임의 보상 텐서는 게임 진행 중 고정된다.
- 에이전트는 행동별 계수와 규칙을 상호작용을 통해 파악해야 한다.

이는 매 턴 보상을 무작위로 생성하는 방식과 다르다.

### **7. 연구와의 연결**

핵심 연구 목표는 **Multi-Agent 환경에서 Meta-Policy 학습이 새로운 게임 규칙과 상대 전략에 대한 Exploration 및 Adaptation 능력에 미치는 영향을 분석하는 것**이다.

논리적 Rule Generator를 사용하면 단순히 게임의 수를 늘리는 것이 아니라, 게임 사이의 구조적 유사성과 차이를 통제할 수 있다.

이를 통해 에이전트가 개별 게임의 보상을 암기하는지, 아니면 공통된 논리적 구조를 학습하여 새로운 게임에 활용하는지 실험할 수 있다.

**현재 우선 구현 대상은 공통 게임 환경과 논리적 Rule Generator를 연결하여, 서로 다른 규칙으로 생성된 게임을 에이전트가 실제로 플레이할 수 있는 기본 실험 구조다.**
