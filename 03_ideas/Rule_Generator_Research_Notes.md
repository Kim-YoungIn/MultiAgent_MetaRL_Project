# Rule Generator와 게임 간 차이 — 검토 노트

상태: 검토 후보를 보존한 문서. D-018은 연구 우선순위를 조정했으며 아래 모든 기능을 채택한 것은 아니다.
출처: 사용자 전달 Handoff·후속 생각노트, 동료 메모, 메인/독립 검토.

## 중심 아이디어

논리 규칙 생성은 게임 수 증가보다 학습 분포의 공통 구조와 차이를 통제하는 도구다.
기존 환경·Compiler·기록을 재사용하고 primitive/조건/결합/계수/생성 provenance를 기록하는
제한된 문법으로 전체 실험 흐름을 연결하는 방향을 검토했다.
구체 문법과 계수 범위, 상대군, 실험 규모는 아직 확정하지 않았다.

## 분리할 변화

- Parameter: 같은 구조에서 계수·비용·위험도 변화.
- Composition: 익숙한 관계의 새로운 조건·결합.
- Novel relation: 학습에서 제외한 논리 관계. 전이가 보장되는 조건은 아니다.
- Opponent: 같은 보상 규칙에서 상대 반응 변화. 게임 규칙 거리와 별도 축.
- Action count: 현재 n=3 유지 가능. n=4/5 실행 가능성과 학습 일반화는 구분.

## 거리/비유사도 후보

| 층 | 후보 | 한계 |
|---|---|---|
| 구조 | canonical primitive·조건·연산자 차이 | 다른 표현이 같은 함수를 만들 수 있음 |
| 의미 | 컴파일 텐서의 원시/척도 정규화 평균·최대 차이 | 보상 차이가 전략 차이와 비례하지 않음 |
| 전략 | 고정 상대군/예산에서 기준 정책 교차 적용 손실 | 정책 클래스 의존·비대칭; 엄밀한 metric이 아닐 수 있음 |

정확한 중복, 상쇄/0 계수 퇴화, 양의 배율, 행동 재명명 전후 차이를 구분한다.
재명명은 규칙·상대·이력에 일관되게 적용해야 하며, 게임 동등성과 새 행동 매핑 추론은 별개다.
대칭 공통 함수 F의 표는 n^4항목, 현 양쪽 저장은2n^4다. 제한된 문법의 자유도가 n^4라는 뜻은 아니다.
거리·문법 metadata를 연구자가 사용한다는 것이 정책에 규칙을 공개한다는 뜻은 아니다.
평가 모델의 성공 결과를 이용해 사후 거리를 정의하면 순환 논리가 된다.

## 검토한 연구 비교

H1은 규칙 다양성×상대 다양성을 공통 held-out 과제에서 비교한다.
총예산을 맞추면 과제당 노출이 줄어든다는 점과 학습-평가 거리가 함께 변한다는 점을 기록한다.
H2는 비슷한 과제 수에서 재사용 가능한 구조/결합을 조작하는 비교가 후보이다.
zero-shot 성능, 경험 후 개선, 기억 초기화 차이를 구분한다.

모든 게임에 능동 탐색을 강제할 필요는 없지만 exploration 연구에는
행동에 따른 정보 획득 차이와 미래 활용 가치가 있는 하위집합이 필요하다.
상대 유형이 자연스럽게 드러나는 수동 식별 과제도 대조군으로 쓸 수 있다.
완전정보 oracle의 높은 성적만으로 learner가 필요한 정보를 얻을 수 있다고 판단하지 않는다.

## 보류·위험

무한 DSL, 역할 비대칭, self-play, trial 중 확률적 규칙 변경, dual-policy,
LLM 보조, GPU 전환을 첫 완성본에 모두 넣을 이유는 없다.
소규모 과제 성공만 기다리는 경로와 생성기 규모만 키우는 경로 모두 피한다.
모델이 잘 푸는 게임만 사후 선별하지 않고 실패·퇴화 비율도 기록한다.

## 2026-11-14 — 고정 규칙 목록 재검토 (I-022)

사용자 생각노트: 기존의 정해진 규칙 목록이 적절한지 재검토할 필요가 있으며,
모델 한계가 심각하다면 먼저 해결해야 하는지, H1에 적합한 환경이 선제조건인지 질문했다.
구현 지침이나 새로운 채택 결정으로 취급하지 않는다.

검토 후보는 완성된 규칙 이름을 늘리는 대신 다음 층을 분리하는 것이다.

- 입력: 직전/현재의 자기·상대 행동.
- 관계/조건: 일치·불일치·명시한 행동 관계, AND/OR/NOT 등 제한된 조합.
- 보상 연산: 조건 충족 시 보너스/비용, 우선순위 또는 조건부 대체.
- 생성 제약: 표현 깊이·항 수·계수 범위와 사용한 구성요소를 기록.

예를 들어 직전 두 행동이 다르고 이번에 서로의 직전 행동을 선택한 경우의 보상을
별도 완성 규칙을 추가하는 대신 관계식의 조합으로 표현할 수 있다.
모든 언어에는 기본 구성요소가 필요하며, 임의의 조건식을 크게 만들어 사실상 무작위 텐서를
다시 표현하는 것만으로 연구에 유용한 논리 구조가 생기는 것은 아니다.
이 후보는 기존 Memory-One/공통 F/Compiler 구조를 유지할 수 있으나 실제 문법은 아직 미확정이다.

H1을 '만족하도록' 만드는 것과 '검증 가능한 환경을 마련하는 것'은 구분한다.
필요한 대응의 차이, 허용 경험으로의 식별 가능성, 재사용 가능한 관계와 비교할 분포를 마련하되,
다양성의 효과는 공통 held-out 과제의 사전 정의한 비교로 판단해야 한다.
기억이나 정보 활용의 이득은 H1의 다양성 효과를 보장하지 않는다.

현재 신경망 학습의 한계는 관찰했지만 전체 연구를 막는 표현 불가능성을 입증하지는 않았다.
실험을 무효화하는 계산 오류/확인된 표현 불가능성은 먼저 해결하고,
학습 성능 정체는 제한된 참조 비교와 함께 전체 실험 설계 안에서 다룬다.

## 후속 채택과 구현 — 2026-11-14

후속 프로젝트 진행 요청으로 D-019/D-020의 제한된 문법과 연결형 실험을 구현했다.
위 후보 전체가 채택된 것은 아니며, 문법의 적용 범위·최초 sampling bias·평가 조건은
`../04_design/Generated_Transfer_Contract.md`에 명시했다.
첫 sampler는 현재 행동 일치 관계를 공통으로 포함하며 무제한 논리 게임 생성기는 아니다.
전략 거리·새 primitive 발견·행동 수 일반화는 여전히 별도 과제다.
