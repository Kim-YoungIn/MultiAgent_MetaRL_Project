# 학습하는 상대가 있는 게임에서의 빠른 적응 실험

**D-031 · 2026-11-19 설계 확정 · 2026-11-21 규칙 생성 분포 개정**

새 게임에서 같은 학생과 같은 수의 상호작용을 주었을 때, **학생의 후속 성능을 목표로 훈련한 탐색자**가 **자기 게임 보상을 목표로 사전훈련한 탐색자**보다 좋은 경험을 일찍 수집하는가? 비교의 대상은 다수의 게임에서 PPO로 훈련한 두 탐색 정책이다. 학생은 매 과제 처음부터 학습한다. 결론의 범위는 아래의 게임 분포, 상대 학습법, 적응 예산이다.

### 한 번의 시행

1. 숨은 규칙 하나와 상대 학습 설정 하나를 뽑는다. 두 플레이어는 동시에 행동한다. 각자의 관측은 직전 자기 행동·상대 행동·자기 보상·episode 시작 표시다. 초기 두 행동은 독립 균등, 초기 보상은 0이다. 규칙과 상대의 ID, 남은 턴 수는 비공개다.
2. 탐색자가 학생을 대신해 k턴 행동한다. 학생은 이 경험으로 Q를 갱신하고 상대는 자기 보상으로 학습한다. 탐색자 기억과 양쪽 Q는 시행 시작에 초기화한다.
3. 같은 규칙으로 새 episode를 시작한다. 학생이 greedy로 H=24턴 행동하며 계속 학습하고 상대도 계속 학습한다. 상대와 학생의 Q와 난수 상태는 episode 경계를 넘는다. 마지막 탐색 TD 갱신은 평가 reset 관측으로 bootstrap하고 평가 마지막 턴은 terminal로 처리한다. 최종 평가에서 신경망 가중치 갱신은 없다.
4. 탐색 직후 학생 Q만 지운 분기를 같은 상대 상태·reset·난수로 H턴 더 평가한다. 자연 분기의 평균에서 이 분기의 평균을 뺀 값이 G다. 자연 MA의 성능에는 학생 경험과 탐색이 유도한 상대 상태가 모두 기여한다.

### 최종 아키텍처와 훈련 조건

탐색자는 **행동별 GRU와 모든 행동의 기억을 요약한 벡터를 함께 쓰는 actor**로 확정한다. 기존 action-set의 행동 재명명 등변성과 가변 n 입력을 살리면서 다른 후보의 이력이 두 행동 사이의 선호를 바꿀 수 있게 한다. 성능순위를 가정하지 않고 설계 적합성으로 선택했다.

- 행동 i의 입력은 기존과 같은 자기/상대 직전 행동 일치 표시, tanh(직전 보상/4), 시작 표시, 1/n이다. 공유 GRU(입력 5, hidden 32)로 hᵢ를 갱신한다. m=meanᵢ hᵢ, logitᵢ=MLP([hᵢ,m]), value=MLP(m)이다. 두 MLP는 hidden 32, tanh, 스칼라 출력이다. 탐색 행동은 softmax에서 표본화한다. 관측으로부터 순환 상태를 만들고 별도 규칙 레이블을 입력하지 않는다.
- 학생은 기존 full-key OnlineQ, α=.5, γ=.95, 0 초기화, 평가 동률은 균등 추첨이다. 학생에게 전달되는 것은 실제 순차 전이이며 탐색자 hidden을 전달하지 않는다. 이 선택은 수집 전략과 경험 활용 알고리즘을 따로 바꿀 수 있게 한다. 보상값을 포함한 Q 키의 재방문율과 후속 상태 재사용률을 반드시 함께 보고한다.
- 훈련 상대는 Q(α=.3, ε=.15)와 Expected SARSA(α=.5, ε=.2)를 등확률로 뽑고 γ=.95로 둔다. 새 상대 설정은 Expected SARSA(α=.7, ε=.1)다. 이 설정에서의 전이는 이미 접한 알고리즘의 파라미터 전이다.
- 방법 **M**은 각 탐색 행동의 PPO target을 trial의 G로 둔다. 방법 **P**는 같은 탐색 episode의 평균 자기 보상을 모든 탐색 행동의 terminal target으로 쓴다. 고정 길이에서 이는 기대 탐색 누적 보상과 같은 순위이며 후속 학생 점수는 최적화에 쓰지 않는다. 양쪽 모두 동일한 평가/경험 제거 분기를 계산하고 기록한다. **O**는 M과 같은 목표로 훈련하되 첫 관측 이후 실제 관측을 차단한다. 자기 직전 선택과 n만 허용하고 상대 일치·보상은 0, 시작 표시는 false로 입력한다. O도 순서가 있는 탐색 계획은 학습할 수 있다. 학생·상대는 세 방법 모두 실제 관측을 사용한다.
- 모든 훈련은 K=24, H=24, 800 updates × 32 trials, 배치 32, update당 PPO 3 epochs, Adam lr=.003, clip=.2, value 계수 .5, entropy 계수 .01, gradient norm 상한 .5다. 초기화·과제 표본·환경 외생 난수를 짝짓고 행동에 따른 경로 분기는 허용한다. 평가 checkpoint는 800으로 고정한다. 무학습 대조는 같은 초기 가중치, 균등 랜덤, 학생 Q에 대한 ε=.2 탐색, 반복/변경 50:50이다. 계산량·메모리·실제 소요시간도 방법별 기록한다.

### 규칙 생성과 탐색 필요성

공통 함수 F(p,q,a,b)는 이전과 현재의 양쪽 행동으로 정해진다. 두 사람 보상은 F(p,q,a,b), F(q,p,b,a)이며 독립 보상항은 n⁴개다. 생성 분포는 diverse_relational에서 파생한 D-031 v2다. 숨은 보상 가족에서는 행동 역할에 붙는 보너스에 seed로 뽑은 0.5~1.5의 양수 배율을 적용한 뒤 정규화한다. 훈련과 평가 양쪽에 같은 분포를 적용한다. 이전 정수 계수만 쓰면 n3의 원식 1,728개를 전수 열거해도 정규화·행동 재명명 후 고유 보상표는 52개다. 과거 및 훈련 규칙을 제외하면 2개가 남아 목표인 16개를 채울 수 없었다. n=3에서 broad 32개 훈련 규칙이 주 조건이다. broad는 사회적 유인·상성·상호이력·숨은 보상 각각 8개, focused는 상성 32개다. 생성기 내부에서 논리식을 컴파일하고 양의 affine 정규화로 실제 보상을 [-1,1]에 맞춘다. 예외 조합은 별도 recipe다. 모든 게임에 같은 탐색 보너스를 삽입하지 않는다.

수학적 검사는 실제 최종 보상표에 적용한다. 고정 논리 기저의 가산 부분은 F=Φw다. 서로 다른 계수가 같은 표를 만드는 경우와 행동 재명명 중복은 같은 수로 세지 않는다. 모든 상태와 상대 행동에서 자기 행동 간 보상 차이·동점·공통 최선반응, 각 관계항의 사용률을 집계한다. 이 검사가 보장하는 것은 단계별 유인이다. 상대가 학습하는 반복 게임에서의 정책 차이는 자연 MA 평가에서 측정한다. 역할을 재명명한 숨은 규칙은 구조 개수로는 하나여도 관측에서 역할을 알아내는 난도가 생길 수 있다.

탐색의 유용성은 **분포·허용 관측·상대·예산**의 속성으로 판정한다. 양성/음성 수학 대조는 기존 probe의 균등 θ prior, 알려진 고정 safe 상대, 원보상, temporal bonus 0에서 정확 계산한다. 2턴에서 정보 활용 최적값 2.9 대 무정보 2.0, 1턴 또는 safe 보상 4에서는 순정보가치 0을 재현해야 한다. 이 대조는 정확 계산기의 인수 자료다. 넓은 분포에서는 다음 검사를 추가한다.

- 각 n·각 평가 분할의 규칙을 생성 순서대로 같은 family 내 두 개씩 짝짓는다. 균등 prior, 2턴, 균등 독립 상대, 실제 정규화 보상을 고정한다. 균등 초기 joint state를 관측한 뒤 가능한 첫 행동·상대 행동·보상을 전수 열거한다. 둘째 턴에는 (i) 전체 이력으로 posterior 갱신, (ii) 같은 물리적 상태와 행동 이력은 쓰되 첫 보상을 가린 두 최적 계획의 총기댓값을 각각 구한다. 차이는 이 조건의 보상 관측 가치다. 즉시 기대보상이 최대인 첫 행동만 허용한 최적 계획도 풀어, 정보 활용과 즉시보상을 희생하는 탐색의 이득을 구분한다.
- 가족별로 보상의 식별 가능성, 같은 최적 대응의 비율, 위 두 가치의 분포와 0인 비율을 공개한다. 양성 사례만 골라 훈련하지 않는다. 실제 MA에서의 정보 활용은 M/O 비교 및 아래의 경험 교차 대조로 따로 확인한다. 같은 규칙 쌍에서 2턴 검사를 두 실제 학습 상대의 빈 Q에서 시작해 한 번씩 반복한다. 상대는 자기 보상으로 첫 전이를 학습한다. 갱신 후 두 번째 행동 분포를 각 숨은 규칙별로 계산해 기대값에 넣는다. 기준 정책에 허용하는 정보는 실제 관측 또는 첫 보상 마스킹 조건으로 한정한다. 이 계산은 2턴 prior에 대한 환경의 증거다. 양의 가치가 관찰된 층과 0인 층 모두 본 평가에 남긴다. 양성 층이 없으면 환경의 탐색 필요성은 해당 감사에서 미확인으로 보고한다.

### 과제 분할과 반복

훈련 catalog 번호 c=1…5에 seed 31000+c를 부여한다. 각 catalog에서 n별 broad 128개를 먼저 만들고 균형 prefix 8/32/128을 사용한다. focused도 같은 생성 설정을 사용한다. 생성 API의 fresh/structural 개수는 각각 16으로 고정한다. 구현 점검 전용 catalog seed는 21001, 훈련 seed는 22001이다. 최종 훈련 catalog의 내부 분할은 폐기하며 모델 선택에 쓰지 않는다. 훈련 seed는 catalog별 41000+100c+j, j=1…5로 두어 독립 초기화 5개를 중첩한다. 같은 c,j의 방법 간에는 같은 seed를 쓴다.

최종 규칙은 n별로 **fresh 64개**(네 가족당 16개)와 **exception 64개**를 따로 만든다. 해당 n의 모든 훈련·개발 규칙, 이미 점수를 열어 본 catalog, 두 최종 분할 사이에서 정규화 후 canonical fingerprint 중복을 허용하지 않는다. 독립 seed 51000+n으로 같은 개정 생성기의 평가 후보를 뽑고, 충돌 시 같은 가족의 다음 후보로 채운다. 원식·정규화·거부 수·분할 hash와 source 버전을 실행 전에 봉인한다. 과거 산출물 중 manifest 회수가 불가능하면 중복 검사 범위를 기록한다. 대표 n3 패널은 훈련에서 접한 두 상대 각각과 교차한다. 동일한 새 규칙을 새 상대 설정과도 교차해 규칙 전이와 상대 설정 전이를 비교한다. 각 n의 모든 방법·훈련 catalog는 같은 최종 패널을 사용한다. 규칙당 각 상대 설정에서 시행 8회, 평가 seed는 SHA256(n,split,rule_id,profile,rep,61001)의 고정 직렬화(UTF-8 JSON 배열, 공백 없음) 앞 8바이트를 big-endian 정수로 사용한다. seed에서 방법·k·훈련 seed를 생략해 짝지을 수 있다.

### 비교할 조건과 계산 예산

| 질문 | 훈련 조건 | 추가 훈련 수 |
|---|---|---:|
| 주가설, 경험 조건부 탐색 | n3 broad 32, 혼합 상대에서 M/P/O, 5 catalog × 5 초기화 | 75 |
| H1 규칙 수 | n3 broad 8과 128, 혼합 상대에서 M/P | 100 |
| H1 상대 다양성 | n3 broad 32, Q만 / SARSA만 학습 상대로 사용, M/P. 두 단일 조건 평균과 혼합 조건 비교 | 100 |
| 가족 범위와 H2 전이 | n3 focused 32, 혼합 상대, M/P. 공통 평가에서 contest·나머지 세 가족·예외 분할별 차이 보고 | 50 |
| 행동 공간 전이 | n5 broad 32, 혼합 상대, M/P. n3와 n5 모델을 각각 n3/4/5에서 가중치 고정 평가 | 50 |

각 행에서 생략한 설정은 주 조건과 같다. 1회당 실제 1,228,800턴과 제거 대조 614,400턴이다. **주 질문은 75회·138,240,000 simulation steps로 독립 완결**된다. 확장 전체는 주 질문 포함 375회·691,200,000 steps이며 평가·진단 비용은 별도다. 주 질문부터 실행하고 각 확장은 표의 순서로 완결된 블록 단위로 보고한다. 자원 제한이 있으면 미실행 블록은 명시한다. 주가설 표본 수와 checkpoint는 결과에 따라 늘리거나 줄이지 않는다. 같은 총예산에서 규칙 수가 늘면 규칙당 노출은 줄어든다. 실제 노출을 보고하며 이 추정량은 고정 총예산의 효과다.

H2의 조작적 예측은 훈련 요소가 공유되는 미학습 조합에서 M의 이점이 나타나고, 같은 N에서도 훈련 생성 범위에 따라 전이가 달라진다는 것이다. 지속적인 탐색 우위는 동일 가족 새 계수, 미학습 가족(focused의 경우), 예외 조합에 대해 각각 판정한다. 가족별 난도와 훈련 노출이 함께 변하므로 이 결과로 특정 primitive의 인과 기여까지 결론 내리지 않는다. 훈련에 없던 n에서의 비교는 동일 n 내 M−P로 한다. n 사이에는 상성표와 GRU 기억량 n×32가 달라진다.

H2에는 성능과 독립적인 재사용성 지표를 사전 지정한다. 같은 n에서 각 훈련 규칙과 최종 규칙의 3턴 최적 대응을 두 진단 상대(매턴 균등, 직전 내 행동을 복사) 각각에 대해 후방 계산한다. 양쪽에 같은 상대를 쓰고 초기 joint state에 균등 가중한다. 훈련 규칙의 정책을 최종 규칙에 적용했을 때 최적값에서 잃는 평균 보상을 계산한다(최적 행동 동률은 균등). 재명명은 상태·상대·행동에 같은 순열을 적용하고 두 상대 평균 손실이 최소인 정렬을 쓴다. 규칙별 최솟값을 훈련 집합과의 전략 차이로 기록한다. 동일 N=32에서 규칙별 손실과 그 규칙의 paired A(M)−A(P) 사이 Spearman 상관을 가족 안에서 계산한다. 사전 예측은 음의 방향이다. 상수열이면 미정의로 표시한다. 이것은 제한된 상대·horizon에서의 진단이며 본실험 상대의 학습은 계속된다.

### 적응 속도와 판정

k∈{0,3,6,12,24}에서 같은 trial seed로 탐색을 각각 k턴 실행한 뒤 고정 H=24턴의 자연 MA 후속 평균 R(k)를 측정한다. 각 k의 마지막 탐색 전이는 해당 평가 reset을 향해 따로 갱신한다. k=0에서는 빈 학생과 새 상대를 곧바로 평가한다. 모든 방법의 R(0)은 짝별로 같아야 한다. 이 값에는 학생의 24턴 온라인 학습이 포함된다. 별도로 평가 첫 턴과 첫 3턴의 보상을 보존한다. 탐색자의 사전 선호는 탐색 첫 행동·첫 보상, 전체 k턴 게임 보상, O의 성적으로 점검한다.

주지표 A는 **R(k)−R(0)을 k축에서 사다리꼴 적분해 24로 나눈 값**이다. 같은 수의 경험을 얻고 학생에게 제어권을 넘겼을 때의 성능을 여러 전달 시점에 걸쳐 측정한다. 가중치는 k 순서대로 (1.5,3,4.5,9,6)/24다. 점수가 높은 시점이나 기울기를 사후 선택하지 않는다. 주 효과는 n3 broad 32 혼합 훈련의 **fresh 규칙·두 훈련 상대 설정에서 A(M)−A(P)**다. rep→규칙→가족→상대에 동일 가중치를 주고 방법별 차이는 같은 task/seed에서 먼저 계산한다.

- 주 효과의 양측 95% 구간 하한이 0보다 크면 이 분포와 학생에서 후속 적응을 목적으로 한 훈련이 평균 경험 효율을 높였다고 판정한다. 상한이 0보다 작으면 저하, 0을 포함하면 불확실로 보고한다. R(3), R(6), R(12), R(24)의 절대점수와 paired 차이를 모두 제시한다. 이점이 24턴에서만 나타나면 후기 성능 이점으로 기술한다.
- O보다 우수하면 관측 조건부 탐색의 추가 가치와 합치한다. 비슷하면 학습된 공통 행동 순서로 설명될 여지가 있다. 랜덤·초기·ε 탐색 대비 결과, 예외·새 상대 설정·행동 수 전이, H1/H2는 보조 분석이다. 시험한 모든 조건의 효과와 구간을 공개하며 주 판정은 위 한 건으로 제한한다.
- 같은 실제 예산 B=48에서 각 k에 대해 후속 H=48−k로 다시 평가하고 (탐색 보상 합+후속 보상 합)/48을 보고한다. 탐색 비용과 후속 이득의 교환을 보여준다. 이 보조 비교는 주 조건 M/P/O와 랜덤에 적용한다.
- 관측 이력을 이용하는 메커니즘의 보조 검사로 주 조건 M과 P에서 매 탐색 턴 직전 GRU hidden을 0으로 초기화한 동일 checkpoint도 위 원인 분석 표본에서 평가한다. 현재 관측에 대한 반응은 가능하다. 훈련 때와 다른 입력 이력의 영향이 포함되므로 학습된 O 대조와 함께 해석한다.
- 주 신뢰구간은 paired 계층 bootstrap 10,000회, seed 71001, 2.5/97.5 백분위다. catalog를 복원 추출하고 각 catalog 안에서 훈련 seed 쌍을 재표집한다. 주 추론은 봉인된 평가 패널에 조건부다. 다섯 catalog별 차이와 한 catalog씩 제외한 민감도를 함께 공개한다. 규칙 표집 민감도는 같은 가족 안에서 규칙을 재표집해 모든 방법·모델에 공통 적용한다. k·행동·분기를 독립 학습 반복으로 세지 않는다.

### 원인 분석과 실행 인수

주 조건의 c=1…5, j=1, 평가 fresh 각 가족 첫 4개, 두 상대, rep 0·1, k=12에서 M/P/random의 수집 기록과 상대 상태를 3×3 교차한다. 같은 reset·난수로 원래 학생 Q를 재생하고 online·학생 Q 동결 두 방식으로 H=24를 평가한다. 상대는 계속 학습한다. 자연스러운 대각선과 교차 순위가 다르면 상대 상태에 대한 민감도를 보고한다. 같은 기록으로 full Q와 기존 보상 부호 Q의 상태 재사용과 성능도 비교한다. 서로 다른 학생 표현은 보조 대조에만 사용한다.

구현된 기반은 n3/4/5 tensor/Compiler, 두 학습 상대, PPO와 G, catalog 생성·중복 검사, checkpoint 재개, 경험 재생·교차 평가다. 독립 실험 패키지 `experiment/`가 평균 기억을 actor에 전달하는 모델과 checkpoint 형식, P/O 훈련, k=0 및 k별 경계 처리, 평가 패널 봉인·중복 검사, 2턴 수학 검사, 집계·통계 실행기를 제공한다. 이전 186개 회귀 테스트와 D-029/D-030 실행은 선행 구현의 근거다.

최종 점수를 열기 전에 개발 manifest에서 행동 재명명 등변성, 단건/배치 출력과 재개 일치, P/O 정보 차단, 각 k의 reset bootstrap, k=0 동일성, 세 방법의 step 장부, 교차 대각선 재현, 수학 대조값을 검증한다. 궤적은 사전에 지정한 원인 분석 표본에 저장하고 전 시행의 seed·곡선·요약은 보존한다. 실패한 run은 같은 설정과 seed로 재개하고 수치 발산·인프라 실패·미완료를 별도로 공개한다. 빠진 방법 쌍이 있으면 주 판정을 보류한다. 봉인 이후 오류 수정은 버전과 영향 범위를 남기고 영향받은 모든 비교군을 재실행한다.

이 명세가 D-030의 36회 개발/75회 확대 초안과 이후 생각노트의 후보 선택을 대체한다. 유용한 탐색 정보의 존재, 학생의 활용, 학습 상대의 반응이 실제로 어떤 결과를 내는지는 본실험에서 측정한다.
