# Can a policy learn which move to make for information?

New study after the structured-game opportunity and size-transfer panels were opened. Locally committed before scoring the new final stream. The question concerns a learned two-decision policy with limited public history and simulator supervision. An agent gets four uniform calibration interactions with a fresh three-action, depth-three structured game, makes one opening move, and then selects a terminal response. Both scored rewards count. Four original generator motifs are equally frequent. A simultaneous epsilon-greedy Q learner uses the last joint action pair, alpha=.3, gamma=.8, epsilon=.25, zero initialization. A new game and a new opponent are drawn at each task reset. The agent sees its own reward, joint actions, two zero-padded public state slots and bounded public history. Game seeds, motif, hidden state, role labels, opponent reward and Q parameters are unavailable to the policies.

## Interventions

For each calibration history simulate all three possible opening moves. Use one common opponent uniform and one common transition-gate uniform across the branches. The opponent chooses before seeing the opening. At each terminal query integrate over its full simultaneous action distribution. A single frozen terminal policy receives the opening joint move and resulting public state in every cell. When the first focal reward is visible its numerical value and a visibility flag enter the policy. When masked, both are zero. In both cases the experimenter still scores the original opening reward.

In **live** play the world and opponent carry the opening forward. In the **rewind** assay both return to their exact pre-opening state, with the original hidden state, joint history and opponent Q table, while the agent retains the opening transcript. The terminal action is scored directly at that restored state. The two cells differ only in physical continuation and the policy's knowledge of the regime. No further transition sampling is needed. In rewind, the opening can change terminal reward only by changing what the agent learns or does with the transcript. Masking its numerical reward leaves the joint action and public transition informative. A separate post hoc calculation freezes only the opponent's opening Q update at the live post-state, holding selected terminal actions fixed. This evaluates payoff sensitivity to that update.

## Learning and comparisons

Use two fresh disjoint training sets per block. Fit a shared terminal value network by squared error against expected immediate terminal payoff for every candidate action, with the same examples both visible and masked and both regimes. Then freeze it. On distinct opening-training games evaluate each branch using its chosen terminal response in each regime/channel. For each candidate opening regress five quantities with one shared network: expected immediate reward, masked continuation value and the realized visible-minus-masked continuation increment in each regime. This decomposition enforces identical myopic scores and a shared masked-return estimate in a comparison of openings. Inputs give the opening network only the calibration history and current observation. The opening trained for visibility adds its estimated increment to the masked objective. The myopic opener maximizes the same network's immediate-reward estimate. Ties choose lowest index. Include a uniformly sampled opening integrated over all three alternatives with the same terminal controller and a conventional online shrinkage-mean greedy controller. The latter uses the sum of observed focal rewards for each action divided by one plus its count, updates when reward is visible, and has no offline training.

Both networks share their weights across action labels; features encode candidate matches to history, public state and reward. They have two 64-unit SiLU hidden layers. Conditional outputs are standardized using only their own training targets. Fixed AdamW learning rate .002 and weight decay .0001, with 800 terminal minibatches of 384 rows and 600 opening minibatches of 256 rows, sampled with replacement. One initialization per independent catalog. No policy parameter update at evaluation. These are amortized, history-conditioned decision policies with a supervised outer training signal. All arm comparisons within the neural system share every training branch and predictor. Both training sets use privileged, simulator-computed expected action values as labels. This design measures what can be learned with that access.

## Frozen primary estimands and replication

For each regime write V(o,c) for the expected two-turn payoff of opening policy o and the common terminal controller using channel c. Opening policies v and m specialize to visible and masked feedback in that regime; g is myopic. Two directional predictions, judged using two-sided intervals:

1. Live deployment improvement, V(v,visible) − V(g,visible) > 0. Future benefits must compensate for an opening reward sacrifice.
2. Rewind reward-channel interaction, [V(v,visible) − V(m,visible)] − [V(v,masked) − V(m,masked)] > 0. The physical state is common to all openings. Immediate reward cancels algebraically. A positive interaction identifies learned opening selectivity for this reward channel and this terminal controller. Also report both cell differences, the four absolute outcomes, and whether v improved the visible-channel return.

Two paired bootstrap intervals at 97.5% each (two primary endpoints, nominal familywise 95%), 20,000 resamples of whole independent blocks using seed 2817601. Each block has its own games, reset randomness and network initialization. Equal-weight averaging over samples within block gives equal game and motif weights. Main test uses 256 games × 2 resets, with four prefix moves. Final uses 16 independent blocks. Training uses 512 games × 4 resets for each stage in each block, always at prefix four. Additional independently drawn panels at prefix zero and eight use 64 games × 2 resets each per block. The network sees at most the last four calibration steps in these shift assays. Comparisons across these panels cannot isolate the effect of adding observations for a fixed state.

Report prefix, motif, input masking, opener agreement, first/terminal reward, achieved information benefit and opponent-update diagnostics descriptively. Include the hindsight maximum over realized branch returns as a privileged opportunity bound for this decoder, with its selection optimism identified. The control with a random opener measures use of feedback without strategic opening selection. All endpoints count the cost of the opening. No tuning or extra final replication conditional on outcome. Development seed 591302 and final seed 67021843. Preserve source/configuration manifests, weights, training data, public histories, full branch outcomes and selected actions. Historical runs are untouched.
