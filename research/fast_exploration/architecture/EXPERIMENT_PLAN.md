# Fast Exploration 실험 계획

새 결과를 확인할 때마다 판정에 필요한 후속 비교와 새로 구분할 원인을 이 표에 추가한다. 정규 실행을 시작한 실험은 해당 프로토콜과 시험 규칙을 봉인한다.

| 실험 | 진행 기준 | 정규 비교와 범위 |
|---|---|---|
| v2 피드백과 prior | 관측 활용과 강한 초기화의 효과를 구분 | pooled/IPS × 전체/차단, 학습 상대와 통제 평가. 개발 4블록 검증, 정규 36블록 실행 |
| v2 학습 목표 대조 | 무작위나 탐욕만으로는 훈련 기회의 효과가 남음 | pooled에서 후속 보상과 즉시 보상의 동일 학습량 비교 |
| v2 48턴 고정 배치 | 탐색 비용이 후속 성과를 상쇄할 수 있음 | 환경과 상대가 계속 변하는 48턴, K=8에서 전체 보상 목표와 후속 보상 목표 비교 |
| v2 행동과 상대 | 호혜의 반복 행동과 Q 상태가 평균에 영향을 줄 수 있음 | 역할·반복률, 탐색 중 상대 동결, 평가 Student·Q 복원 2×2, 공통 관측 문맥 |
| 반복률을 맞춘 비학습 탐색 | v1 K=24에서 Learned의 반복률이 계열별 40–42%, 무작위는 33–34%였다. Learned의 가장 빈번한 행동 번호 비중은 35–36%였다. | 개발 자료로 반복률을 맞춘 확률적 탐색을 새 패널에서 비교하고 호혜 게임의 Invest 선택과 유용한 경험의 차이를 측정 |
| v2 규칙 유사도 | 실제 훈련 게임과의 거리가 정책 차이를 조절하는지 확인 | 계열·블록별 상관, 연구자 계산 서명, 전이가 상수일 때 정의 불가 기록 |
| 96턴 배치 전이 | 비용을 회수할 시간이 48턴을 넘는지 확인 | [고정 정책 확장](V2_HORIZON.md), 새 규칙 패널 |
| 96턴 UCB 비교 | 48턴 K=8에서 전체 보상 Teacher가 Student 단독을 앞섰지만 UCB보다 낮았음 | 열린 96턴 패널에 개발에서 고정한 UCB β=.15를 짝지어 추가한다. K=8·24의 48·96턴 누적 보상을 탐색적으로 집계 |
| 배치 중 탐색 종료 | 전체 보상 Teacher의 K=8과 K=24가 48턴 예산에서는 반대 방향의 차이를 보였음 | K를 개발에서 미리 고르는 정책과 남은 예산에 따라 탐색을 끝내는 정책을 비교한다. 48·96턴 예산과 학습 상호작용을 맞추고 다른 새 패널에서 UCB·Student 단독을 비교 |
| 전이 유사도의 분해능 | 개발 16개 블록·계열 조합에서 행동 재명명 후 전이 유사도가 모두 상수 | 같은 계열에서 전이 확률·시간 지연을 조작하고 보상 규칙은 짝지어 유지하는 새 생성기 비교 |
| 훈련 다양성 | v2 유사도는 관찰적이며 다양성의 효과는 별도 훈련 개입이 필요 | 동일 학습 상호작용과 카탈로그 크기에서 계열 혼합을 바꾼다. 카탈로그 크기와 게임당 노출은 별도 예산 대조로 분석 |
| 상대와 규칙의 분포 밖 전이 | 동일 생성기·상대의 결과가 미학습 전략 구조에도 유지되는지 확인 | 계열 하나를 제외해서 학습하고, 다른 갱신률 또는 Expected SARSA 상대에 대한 전이를 독립적으로 측정 |
