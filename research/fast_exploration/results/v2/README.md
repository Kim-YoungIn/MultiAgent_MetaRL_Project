# Fast Exploration v2 결과

**새 관측에 반응하는 Teacher는 피드백을 차단한 Teacher보다 유용한 경험을 모았다.** pooled prior에서 증가한 절대 적응 AUC는 +0.00097이었다. 다만 같은 훈련량의 즉시 보상 Teacher와 UCB보다 후속 AUC가 낮았다. 탐색 비용까지 학습 목표에 포함한 별도 Teacher는 48턴에서 K=8에 이득을 내고 K=24에서는 탐색 비용을 회수하지 못했다. 새 96턴 패널에서는 K=8과 K=24 모두 Student 단독보다 높은 평균 보상을 얻었다. [실험 프로토콜](../../architecture/V2_PROTOCOL.md) · [96턴 확장](../../architecture/V2_HORIZON.md)

## 피드백과 후속 적응

3개 master seed의 12블록씩, 총 36블록에서 7개 Teacher를 각각 400업데이트 ×32게임으로 훈련했다. 시험은 블록당 새 게임 128개와 두 리셋에서 짝지었다. 주 비교는 탐색 후 상대 Q를 복원하고 두 학습자를 동결한 32턴 평가다. 아래 구간은 블록 단위의 기술적 95% 대응 구간이다. [시드별 대비](evidence/paired_by_seed.csv)

| 절대 적응 AUC 대비 | 차이 | 95% 구간 |
|---|---:|---:|
| pooled 전체 피드백 − 피드백 차단 | +0.00097 | [+0.00037, +0.00159] |
| IPS 전체 피드백 − 피드백 차단 | +0.00254 | [+0.00108, +0.00413] |
| pooled 전체 피드백 − 즉시 보상 Teacher | −0.00210 | [−0.00334, −0.00080] |
| pooled 전체 피드백 − UCB | −0.00938 | [−0.01096, −0.00775] |
| 상대 Q를 탐색부터 동결한 pooled 피드백 효과 | +0.00073 | [+0.00024, +0.00122] |

pooled 주 비교의 구간 상단은 실질적 효과 기준으로 정한 +0.002보다 낮았다. pooled와 IPS의 피드백 효과 차이(−0.00157 [−0.00344, +0.00011])와, 상대 갱신 유무에 따른 pooled 피드백 효과 차이(+0.00025 [−0.00016, +0.00065])는 0을 포함했다. 상대 Q만 보존하는 개입에서 얻은 pooled 피드백 효과는 −0.00010 [−0.00046, +0.00024]이었다. 공통 관측 문맥의 K=8 Student 선택 가치는 +0.00066 높았다. [적응 곡선](evidence/adaptation_pooled_controlled.png) · [대응 비교 원수치](evidence/paired.csv)

호혜 계열의 pooled 피드백 효과는 +0.00234였다. K=24에서 이 계열의 전체 피드백 Teacher와 차단 Teacher의 행동 반복률은 각각 34.4%, 33.9%였다. 실제 훈련 규칙과의 보상 유사도와 피드백 이득의 계열 내 Spearman 평균은 +0.0052 [−0.0174, +0.0284]였다. 전이 유사도는 144개 블록·계열 조합에서 상수여서 상관을 계산할 수 없었다. [유사도 자료](evidence/similarity_strata.csv)

## 전체 예산 고정

48턴은 양쪽 학습자와 환경 상태가 연속되는 배치 길이다. 비교한 두 Teacher는 같은 48턴 상호작용과 훈련 횟수를 사용했다. 전체 보상 Teacher의 학습 목표에만 탐색 보상 항이 들어갔다. Student 단독 배치는 K=0이며, 같은 K의 탐욕 탐색을 거쳐 Student로 넘겨도 행동과 보상이 매 턴 같았다.

| K | 전체 보상 Teacher − 후속 보상 Teacher | 전체 보상 Teacher − Student 단독 |
|---:|---:|---:|
| 4 | +0.0878 [+0.0366, +0.1359] | +0.1070 [+0.0415, +0.1758] |
| 8 | +0.1700 [+0.1078, +0.2332] | +0.0985 [+0.0272, +0.1698] |
| 16 | +0.4218 [+0.3427, +0.4962] | −0.1086 [−0.2019, −0.0226] |
| 24 | +0.7877 [+0.6805, +0.8946] | −0.4382 [−0.5613, −0.3269] |

K=8의 +0.1700은 탐색에서 +0.1206, 후속 Student에서 +0.0494였다. K=8의 개발 조정 UCB와 비교하면 전체 보상 Teacher는 −0.1202 [−0.2119, −0.0293]였다. [48턴 플롯](evidence/fixed_budget.png) · [UCB 추가 대비](evidence/extra_fixed_ucb.json)

## 별도 96턴 패널

동일한 36개 훈련 블록에서 학습된 정책을 새 게임 4,608개에 적용했다. 각 조건의 48턴 보상은 같은 96턴 궤적의 첫 48턴이다. 모든 수치는 같은 패널의 Student 단독 대비 누적 보상이다.

| Teacher 및 K | 48턴 | 96턴 |
|---|---:|---:|
| 전체 보상 K=8 | +0.0207 [−0.0636, +0.1027] | +0.4456 [+0.2742, +0.6148] |
| 전체 보상 K=24 | −0.4916 [−0.6187, −0.3686] | +0.2173 [+0.0405, +0.3926] |
| 후속 보상 K=8 | −0.1108 [−0.1809, −0.0416] | +0.3508 [+0.1843, +0.5119] |
| 후속 보상 K=24 | −1.2418 [−1.3449, −1.1361] | −0.5096 [−0.7117, −0.3042] |

전체 보상 K=8의 Student 대비 이득은 49~96턴 사이에 +0.4248 [+0.3285, +0.5222] 늘었다. 96턴의 K=8에서 두 학습 목표 간 차이는 +0.0948 [−0.0396, +0.2379]였다. [96턴 플롯](evidence/horizon_curves.png) · [계열·K별 수치](evidence/horizon_paired.csv)

48턴에서 관측한 UCB 결과를 바탕으로, 이미 공개된 96턴 게임에서 같은 UCB를 추가 재생했다. 이 탐색적 대비에서도 전체 보상 Teacher는 96턴에서 UCB보다 낮았다. K=8은 −0.1760 [−0.3080, −0.0382], K=24는 −0.6635 [−0.8334, −0.4995]였다. [96턴 UCB 탐색적 비교](evidence/horizon_ucb_exploratory.csv)

## 검증과 재현

- 36블록의 48턴 고정 길이, 행동 기록, 패널 중복 여부를 확인했다. 원본 스칼라 환경으로 평가 궤적 2,592개와 96턴 궤적 180개의 양쪽 보상을 대조했다. 주 AUC와 고정 예산 대비, 96턴 주 구간은 원자료에서 독립 재계산했다. [검증 기록](evidence/verification.json) · [독립 재계산](evidence/independent_estimates.json)
- 정규 실행 프로세스가 한 번 종료돼 동일한 체크포인트에서 재개했다. 회귀 검사 239개 중 235개 통과, CUDA 의존 4개는 건너뛰었다. [완료 기록](evidence/completion.json)
- 두 플레이어의 실제 행동은 학습과 평가에 턴 단위로 저장했다. Student 입력 특징은 재설정 조건의 탐색에서 직접 저장했고, 동결·연속 조건의 특징은 행동·규칙·시드로 재생할 수 있다. 로컬 원자료는 `runs/fast_exploration_v2_final/`과 `runs/fast_exploration_v2_horizon_final/`에 있으며, 실행·검증·집계 명령은 [아키텍처 가이드](../../architecture/README.md#run-v2)에 있다.
