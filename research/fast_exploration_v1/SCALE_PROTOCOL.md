# Fast Exploration scale run

Follow the Fast Exploration teacher–student architecture, prior-fitting objective, teacher loss, reward, opponent and comparison regimes in PROTOCOL.md. The full run uses master seeds 7311903, 8291309 and 9416819, eight independent training/test blocks per seed. Per block train each of learned and belief-blind for 400 updates of 32 episodes. The prior stage uses 128 independently sampled games and 160 optimization steps. Prior IPS training keeps its original 0/2/4/8/16 grid and regularization. Teacher sampling and all evaluations use K=0/4/8/16/24 and H=32. Teacher budget weights use the positive-K trapezoid weights of this grid. At test each of 128 new games is played from two independent reset streams, paired across all methods and budgets. This differs from drawing 256 independent game rules in the previous patch.

The same actors and evaluation panel are used for the pooled and zero-prior sensitivity comparisons. In controlled assessment, retain the Student coefficients after the probes and restore the warmed opponent. Freeze both learners during assessment. In ordinary play keep the evolving opponent and both updates. A separately seeded episode reset for assessment is identical across opening policies. Both regimes share exploratory prefixes. All K values tally the actual sum of exploratory and assessment rewards. The absolute AUC integrates mean assessment payoff vs. K down to zero using trapezoids. The completed block is the statistical unit, stratified by master seed. Pointwise 95% block intervals are descriptive; the comparison does not distinguish all mechanisms of acquiring information.

The batch simulator follows the compiled rules and uses the same independent random streams for opponents, stochastic gates and action sampling as the scalar reference. There is no change to the REINFORCE, critic, entropy or ridge update formulas. Numerical equivalence of predictions, returns and updates is checked to stated tolerances. Device and source versions are recorded and checkpoint resume rejects an incompatible configuration.
