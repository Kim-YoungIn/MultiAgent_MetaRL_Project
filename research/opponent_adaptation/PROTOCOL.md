# Does a learning counterpart change the value of meta-training for adaptation?

Prospective study. All earlier panels are open. This experiment directly crosses the focal training objective with the counterpart's within-game learning. The controlled population is equally weighted over the four supplied structured game motifs at three actions and history depth three. Task identity comprises a hidden generated game and an opponent with prior experience of it. The focal agent is new to both. Coefficients, action assignments and exact rules vary across games. The public representation is the action-relative 20-feature map from structured_scale, shared across action labels. Every focal method has the same public state, recent joint moves and focal reward, with task-specific adaptation from observed action/reward records. It receives neither the payoff function nor the opponent table or condition.

## Isolating counterpart learning

For each game, warm an epsilon-greedy Q learner for 32 turns against a random focal agent. The opponent observes its reward and previous joint move. Epsilon=.25, alpha=.3, discount=.8. Reset the environment for measurement. Clone the same warmed Q table into two opponents. One continues updating it and one holds it fixed. Both condition their decisions on the current joint-action history. Both receive identical initial game state, random probe actions and per-turn opponent and transition uniforms. Initial policies coincide exactly. Their subsequent trajectories may diverge. This paired total effect includes the resulting state distribution. It conditions on a warmed counterpart; it does not compare multi-agent and single-agent environments.

## Isolating the focal training objective

Both training methods receive exactly the same task-labeled stream of uniform focal actions, public features and realized focal rewards from both opponent conditions. The pooled model minimizes ordinary reward-prediction squared error across those rows. The meta model minimizes the prediction error that would occur *after* updating from earlier experience on the same game/condition. Earlier evidence is taken strictly before the predicted payoff. Both models fit the same 20-parameter initialization w, with a .01 ridge penalty, a single closed-form outer solve, and identical recursive within-game updates. The meta-training computation additionally simulates those updates through each training trajectory. No simulator action-value labels are used in training.

For an action with previous observed features X and payoffs y in that trajectory, define P=(I+XᵀX)⁻¹ and b=P Xᵀy. Starting from w, online ridge regression predicts xᵀ(Pw+b) at the next feature x. Thus post-update error can be minimized by regressing y_next−xᵀb on Px. This is exact optimization of a prequential meta-learning objective in this function class. The pooled solution regresses y_next on x. A common w is shared across action labels, while each action updates its own posterior inside each task. Reset all focal adaptation at each new game and opponent condition.

## Evaluation and two primary endpoints

Each of 24 independent blocks draws 128 training and 128 test games, 32 per motif per split. Each game gets both opponent conditions. The primary uses one common 32-turn uniform focal probe per condition. At k=0,2,4,8,16,32, query the expected focal payoff against the true current opponent mixture for all five controllers: adaptive meta, adaptive pooled, frozen meta, frozen pooled, and adaptive scratch initialized at zero. Frozen focal estimators receive current public inputs and retain their original coefficients. All five decisions face exactly the same state within a condition and k. Counterfactual queries never advance the game. Use paired random permutations to break action ties independently of hidden game roles.

Let U(T,u,e,k) be that payoff for training objective T, enabled/disabled focal updating u, and enabled/disabled counterpart updating e. A(T,e,k)=U(T,on,e,k)−U(T,off,e,k) is the benefit of retaining evidence at the same current state. Predeclare two two-sided contrasts at eight interactions:

1. Absolute meta minus pooled payoff with both focal and opponent updating. This answers which initialization serves a new agent better after equal experience.
2. [A(meta,learning,8) − A(pooled,learning,8)] − [A(meta,fixed,8) − A(pooled,fixed,8)]. This asks whether allowing the opponent to learn changes the *additional* evidence-use benefit of meta-training. Also report all component gains, zero-shot and absolute payoffs, since a worse prior can have more room to improve.

No directional claim from an interval spanning zero. Report paired block means and two 97.5% percentile intervals, using identical 20,000 block bootstrap resamples with seed 384916 for nominal 95% familywise coverage.
