# Reward-signal selectivity at altered terminal stakes

Execution status recorded 2026-11-21. All 16 blocks ran and were verified. [Results and reproduction](REPORT.md)

Prospective diagnostic specified after active_probe v1 was opened and before this follow-up's random game panel was generated. No network weights are fitted in this follow-up. The 16 independent terminal and opening checkpoints from active_probe v1 remain fixed, with hashes checked against their original training manifest and block records. The purpose is to test whether opening decisions become more sensitive to a usable reward signal when the terminal payoff has a larger weight. The reward-channel interaction in the original two-decision study had an inconclusive interval.

## Games and controls

For each checkpoint draw 256 new structured games, with one reset each, balanced across the four motifs, using the v1 generator and a Q-learning opponent. Generate four uniform calibration interactions, then intervene on each of the three opening actions using the same opponent draw and transition gate. The terminal decision uses the rewound pre-opening environment and opponent state, while the agent retains the complete opening transcript. The terminal expected reward integrates over the opponent's action distribution. The first move's physical environment effects and opponent Q update are therefore removed from the terminal payoff, while its immediate reward is still scored. This intervention is the same as the original rewind assay.

At stakes h=1 and h=8, use the same trained opening network, which sees only the calibration history and candidate action. Its output predicts immediate reward I, masked continuation M, and visible-minus-masked continuation increment D in the rewind regime. Define three opening choices by maximizing I, I+h*M, and I+h*(M+D), respectively, and also integrate the uniform opening. These are deterministic functions of the pre-opening transcript and trained parameters. No actual future signal is available when an opener chooses. The network was trained with h=1; this is a change to a decision rule applied to its output rather than end-to-end training at higher stakes.

The common frozen terminal network receives the visibility flag set to one in both signal conditions. The genuine condition provides the opening reward from the recipient game. The sham replaces the vector of all three potential opening rewards with another game's vector; all public fields, opponent action, game, decision, branch payoff and scores remain from the recipient. For each block, create 32 bijective donor permutations. Within each (motif, first opponent action) stratum shuffle the recipient indices using a deterministic RNG, draw one shift uniformly from 1 through group_size−1, and map each shuffled index to the index that far around the cyclic order. Fail if any stratum has fewer than two samples. The mapping is a derangement preserving motif and first opposing action. Save every donor index. Averaging these 32 correlated randomizations estimates the effect of this specified corruption; it does not identify the effect of a conditionally independent reward signal because dependencies on calibration history and counterfactual reward vector persist.

## Endpoints and reproducibility

For each opening policy, compute the average terminal payoff with the genuine reward minus its mean terminal payoff across 32 sham permutations. The one prespecified primary contrast at h=8 is this signal effect for visible-specialized minus masked-specialized opening. Its unit is unweighted terminal reward. Calculate the paired difference within each test block, then 20,000 percentile bootstrap samples of all 16 paired blocks using seed 488021, reporting a two-sided 95% interval. No inference rests on games as independent fits. There is no adaptive stopping. A positive result would support differential dependence on the signal under this corruption and the frozen terminal decoder, with the magnitude and downstream two-turn utility also reported. A null or negative result remains informative.

Report genuine and sham terminal payoffs, opening payoffs, total utility (opening + h*terminal), h=1 outcomes, uniform opening, genuine visible vs myopic return and its opening cost, disagreement between policies, and achieved signal sensitivity. Subgroups and outcomes other than the h=8 interaction are descriptive. Increasing h is a payoff reweighting applied to a one-step terminal reward, not eight real future interactions or an estimated long-horizon return.

Generate each block from np.random.SeedSequence([59183271, block, 1]) for games and [59183271, block, 2] for donor permutations. Use action ties resolved by NumPy argmax. Retain game specs by seed, calibration trajectories, alternative opening rewards, terminal payoff tables, flags, donor indices, model hashes and all chosen actions. Replay uses deterministic generator and exact original code. Keep the 16 games/checkpoint blocks and 32 permutations fixed independent of outcomes. Existing active_probe v1 evaluation games are opened and cannot be reused as untouched samples; verify exact-fingerprint disjointness and record it for all accessible prior training and test sets and the new panel.
