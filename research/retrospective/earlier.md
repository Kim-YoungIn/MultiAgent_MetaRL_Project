# 과거 실험 원자료의 추가 분석

세 실험의 이미 공개된 최종 평가 자료에서 조건별 평균과 개별 게임의 승패를 다시 계산했다. 아래 95% 구간은 독립 훈련 블록 전체를 20,000번 재표집한 사후 기술 구간이며, 여러 조건을 살펴본 데 따른 보정은 적용하지 않았다. [전체 수치](evidence/earlier.csv) · [블록별 수치](evidence/earlier_blocks.csv)

## 같은 경험을 받은 모형과 직접 플레이한 모형

[상대 적응 실험](../opponent_adaptation/REPORT.md)은 메타 초기화와 일반 사전학습 초기화에 같은 8턴 공통 이력을 제공한다. Q 상대가 학습하는 조건에서 3,072개 게임 중 두 모델이 서로 다른 행동을 택한 비율은 14.32%였다. 상대의 현재 행동 확률로 계산한 기대 보상은 전체 게임의 7.06%에서 메타 초기화가, 7.10%에서 일반 사전학습이 높았다. 평균 차이는 −.00015 [−.0028, +.0024]였다. 같은 행동을 택한 게임은 평가 보상도 같았다.

별도 24턴 직접 플레이에서 메타 초기화 − 일반 사전학습의 누적 보상 차이는 −.1788 [−.2526, −.1117]이었다. 첫 8턴이 −.0406 [−.0608, −.0214], 9~24턴이 −.1382 [−.1963, −.0837]였다. 총 24개 블록 중 21개에서 직접 플레이의 차이가 음수였다. 이 비교에서 두 정책은 같은 게임과 난수 스트림을 받지만 자신이 선택한 행동에 따라 게임 상태와 상대 Q의 이력이 달라진다. 따라서 공통 이력의 8턴 즉시 기대 보상과 다른 측정 대상이다.

| 게임 계열 | 공통 이력 8턴의 메타−일반 기대 보상 | 직접 플레이 24턴의 메타−일반 누적 보상 |
|---|---:|---:|
| 자원 | +.0010 [−.0054, +.0077] | +.0534 [+.0003, +.1061] |
| 순서 | +.0042 [+.0013, +.0078] | −.0013 [−.0348, +.0340] |
| 호혜 | −.0067 [−.0130, −.0009] | −.7176 [−1.0151, −.4422] |
| 혼합 | +.0009 [−.0017, +.0032] | −.0496 [−.0858, −.0154] |

계열별 게임 수가 같아 각 계열은 전체 평균의 1/4을 차지한다. 호혜 계열의 기여는 −.1794로, 전체 차이 −.1788과 비슷하다. 다른 세 계열의 기여는 합쳐서 +.0006이다. 호혜 게임에서 일반 사전학습 모델과 플레이한 상대의 누적 보상도 메타 모델과 플레이한 상대보다 평균 .3904 높았다. 정책 선택과 서로 다른 상태·상대 학습 경로가 동시에 바뀌므로 이 수치로 어느 하나의 원인을 특정할 수 없다.

## 유사한 상황에 대한 prior의 승패

[두 맥락 실험](../adapt_v1/PROTOCOL.md)에서 서로 다른 맥락의 숨은 상대 선호가 같은지 여부는 학습할 때 관찰되지 않는다. 평가에서는 숨은 선호가 **같은 게임**과 **다른 게임**으로 나누어, 원래 제시된 75% 일치 prior를 학습한 필터와 독립 prior 필터가 첫 맥락에서 네 번 관찰한 뒤 두 번째 맥락에서 택한 행동의 기대 보상을 비교했다. 두 모델의 0턴 기대 보상은 각 게임에서 일치한다.

| 상대 선호 관계 | learned − independent | 양수 블록 / 전체 |
|---|---:|---:|
| 같은 선호 | +.1813 [+.1610, +.2008] | 32 / 32 |
| 다른 선호 | −.2718 [−.3024, −.2410] | 0 / 32 |

선호 일치 여부는 모델이 게임을 플레이할 때 제공받은 변수가 아니라 평가 후 분류한 변수다. 두 조건의 빈도를 달리하면 모집단 평균이 바뀐다. 예를 들어 75% 일치 모집단으로 표준화하면 차이는 약 +.068이고, 50%라면 약 −.045다. 이 실험에서는 같은 선호에 대한 prior가 같은 선호를 가진 게임에서 이득을 내고 반대 선호에서 더 큰 손실을 낸다. 같은 부호의 재현은 32개의 독립 훈련 블록에 관한 관측이다.

상대가 맥락별로 별도 믿음을 유지하는 구조로 바뀐 기존 변형에서도 두 조건의 평균은 각각 +.1192, −.2107이었다. 이는 해당 구조 변화에 대한 관측이며 모든 상대 학습 방식에 대한 일반화는 아니다.

## 같은 평균 우위도 게임별로는 양방향

[절대 보상 탐색 실험](../absolute_exploration/REPORT.md)은 각 블록에서 256개 게임을 두 번 초기화한 512개 상태를 평가했다. 두 턴 보상을 목표로 학습한 첫 행동과 즉시 보상 정책의 첫 행동은 31.46%의 상태에서 달랐다. 첫 보상의 실현값과 상대의 행동 분포로 평균한 다음 턴 보상을 더하면, 전체 상태의 15.19%에서는 전자가 높고 14.93%에서는 후자가 높았다. 평균 이득은 +.00638이다. 단순한 승리 횟수만으로 평균 성능을 설명할 수 없으며, 같은 첫 행동을 택한 나머지 대부분은 같은 평가값을 가진다.

이 평균 역시 계열에 따라 달랐다. 두 턴 목표 정책의 즉시 보상 정책 대비 평균 차이는 호혜 +.0347 [+.0268, +.0430], 자원 −.0073 [−.0133, −.0016], 순서 −.0046 [−.0072, −.0021], 혼합 +.0027 [+.0004, +.0050]이었다. 호혜의 1/4 기여도는 +.00868로 전체 +.00638보다 크다. 이 수치는 선택된 후보 행동의 공통 시뮬레이션 분기에서 계산한 두 턴 지표다.

## 원자료와 재현

상대 적응은 24개 블록 × 128개 게임, 두 맥락은 32개 블록 × 64개 게임, 두 턴 실험은 24개 블록 × 512개 평가 상태를 읽었다. 각 사용 원본 파일을 해당 블록의 `record.json` SHA-256과 대조했다. 같은 행동의 기대 보상이 같은지, 두 맥락 비교의 0턴 값이 같은지, 계열별 상태 수가 균등한지도 검사했다. 조건별 표본을 먼저 블록 안에서 평균한 후 블록을 재표집했다.

```bash
PYTHONPATH=05_toy_models:. OPENBLAS_NUM_THREADS=1 \
  .venv/bin/python -m research.retrospective.earlier
```
