# Structured-game transfer protocol v1

Written before final simulation. This is a locally frozen protocol, not an externally registered study.

## Question and intervention

Can a population prior estimated across structured games improve online reward prediction and action selection on fresh games with a learning opponent? Does training across four game motifs change that result compared with one motif at equal experience? The observation contains the public state, last three action pairs, previous focal reward and start flag. Hidden trust and rules are never provided to the controller. Simultaneous actions, rewards and public state are observed after each step. Learning opponents and simulator state reset only at the beginning of each test trajectory. The mid-trajectory checkpoints do not reset the game.

The task is a seeded generated StructuredGame with three actions, depth three, three bounded state variables, stochastic transitions, hidden trust, and an independently initialized learner. Each game has generator-selected action roles and payoff coefficients. Randomly sampled task seeds separate train and test. Resource, sequence, reciprocity and mixed are tested separately. Exact serialized fingerprints are checked for all train/test overlaps per block. They do not rule out action-relabeling or strategic equivalence.

Training arms consist of 32 generated games each, 32 turns each. One arm uses resource only, one balances the four families. Each training game is encountered once. Focal and opponent decisions, rewards, observations and generated specifications are saved. Both arms use independent catalogs. The policy collecting training data chooses actions uniformly. Opponent uses epsilon-greedy tabular Q-learning with state equal to its own and the focal player's most recent moves, alpha=.3, gamma=.8 and epsilon=.25. Its initial Q table is zero. This opponent learns from its reward and own state, but does not condition on explicit public state. Identical learner design is used at test. Learning is verified from its update magnitudes.

## Models

Each candidate action has a separate linear immediate-reward predictor. Its input is the intercept, the first two public state variables scaled by 2, previous focal reward, episode-start indicator, one-hot most recent joint action and second- and third-most-recent focal action. Features use observed information only. The unobserved trust state is omitted.

For each action, observations on a game have Gaussian pseudo-likelihood y | w ~ N(Xw,I), with w ~ N(mu, I/lambda), lambda=1. Prior mean mu is fit by maximizing the sum of game-level marginal likelihoods, with a ridge penalty 0.01 on mu. This is empirical Bayes over task-specific predictor coefficients, and learning the prior relies on prespecified representation and likelihood. A standard pooled ridge regression with the same 0.01 regularizer trains on exactly the same records. All online models update a ridge posterior with lambda=1. These simple models are myopic and do not plan for future state or opponent adaptation.

Methods are mixed and resource empirical-Bayes means with posterior updates, each corresponding frozen mean with no updates, pooled mixed mean with no updates, pooled mixed mean with the same online updates, and scratch online regression initialized at zero. They receive the same history. At ties choose action with lowest index. Immediate expected rewards depend on the simultaneously acting opponent.

## Evaluation

Each of 16 independently seeded blocks fits both arms, each from 1,024 interactions, and samples eight test games from each family. Test seeds and all random streams are disjoint from training streams. Each test game has a common 16-turn probe trajectory with uniformly random focal moves and a learning opponent. At k=0,4,8,16, compare action selections against the identical continuing true environment and opponent state, enumerating all current focal/opponent action pairs on cloned environment state and averaging the focal reward by the opponent's current epsilon-greedy distribution. Transitions occur only in the probe, never in these one-step hypothetical queries. Record the exact best response and action values as a diagnostic, plus observed records and fitted weights. Primary endpoint is cross-task average of reward at k=8 minus reward at k=0 for mixed empirical Bayes minus the equivalent scratch difference, weighted equally across families. This difference removes initial offsets, yet can include regression-to-mean and variation in selected actions, and is not a causal effect of memory or an evaluation of optimal sequential control.

The secondary diversity contrast is mixed empirical Bayes minus resource empirical Bayes on the same endpoint, with identical training interactions. Family breadth and exposure to each family vary together. Additionally run each controller on its own fresh 32-turn episode against a fresh learning opponent, sharing the game, reset seed, and paired uniform random streams. Report cumulative reward, first and last eight-turn rewards, opponent rewards, opponent Q changes, public state, action sequences, and unique fingerprints. Paired evaluation controls exogenous randomness but different actions induce different environments and opponent states. This is deployment performance including those responses.

Compute block means and 95% percentile bootstrap intervals over the 16 independently sampled training catalogs and paired test panels, 10,000 draws using bootstrap seed 470919. The primary endpoint is one prespecified comparison. Other analyses are descriptive and exploratory. Fixed budget, no adaptive stopping. Final stream seed 67834219 and development stream seed 4192 are distinct. All seeds, exact specs, observations, actions, rewards, fits, outcomes, code hashes, package versions and runtime are saved. Existing D-031 panels are unused.

## Scope

We measure transfer within the extension's generator and near-term reward adaptation with known feature and likelihood families. Results do not establish optimal information acquisition, long-horizon planning, new semantic game families, general H1 or H2, or a neural meta-RL comparison. Hypotheses may fail under the simple linear predictor. Failed or null results remain reported.
